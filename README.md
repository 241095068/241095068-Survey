# Survey Analysis Tool

このアプリは、研修アンケートの Excel ファイルをアップロードすると、
属性集計・設問別分析・自由記述分類・Markdownレポート出力までを自動で行うツールです。

誰でもURLを開いて使える前提で、GitHub + Streamlit Cloud で公開できる構成になっています。

## 公開URLで使う方法

1. GitHub にこのリポジトリを push する
2. https://streamlit.io/cloud にアクセスする
3. GitHub アカウントでログインする
4. 「New app」を押す
5. このリポジトリと main ブランチを選択
6. Main file path は `app.py`
7. Deploy を押す
8. 発行されたURLを相手に共有する

相手はローカル環境を準備せずに、ブラウザだけで利用できます。

## 使い方

1. Excel ファイルをアップロードする
2. 自動で回答データを読み込む
3. 属性分布、設問別平均、自由記述分類を確認する
4. Markdown形式のレポートをダウンロードする

## ローカル開発時の起動

```bash
cd /Users/fumiko/survey_analysis_tool
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
streamlit run app.py
```

## 前提となる Excel 形式

Excel のシート名は `回答データ` を前提としています。
必要な列は以下の通りです。

- 部門
- 職位
- 性別
- 年代
- 採用区分
- 研修の必要度
- 研修内容のレベル
- 研修の有用度
- 講師評価
- 研修時間
- 研修の満足度
- 研修内容の活用有無
- 活用結果の程度
- 結果の内容
- 上司は重要な意思決定に自分を関与させてくれる
- 上司は部下の能力を伸ばしている
- 会社は社員の意見を十分に取り入れている
- 経営陣や上長に率直に発言できる
- 会社でのキャリアパスを描ける
- 会社に能力を伸ばす機会がある

## 出力内容

- 回答者数と属性集計
- 主要設問の平均値と分布
- 自由記述のポジティブ / ネガティブ / ニュートラル分類
- Markdown形式のレポート出力

## 注意

- このツールはアンケートの標準的な形式に合わせて設計されています。
- 会社ごとに列名や回答形式が異なる場合は、少しだけ調整が必要です。
- 因果関係は断定せず、傾向の把握に留めています。

## GitHub 連携の要点

- GitHub に push したファイルを Streamlit Cloud が自動で読み込みます
- 共有相手は GitHub のアカウント登録不要で URL だけで開けます
- これで「開発者がローカルで起動する」設定ではなく、一般ユーザー向けの公開運用が可能です
